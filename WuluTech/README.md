# WuluTech - 股票指数 AI 分析工具

## 产品定位

**恒生科技指数 AI 分析工具** - 帮助个人投资者分析港股科技板块

## 核心功能

1. **IR 信息聚合** - 恒生科技指数 50 只成份股 IR 信息一网打尽
2. **AI 板块评分** - 基于定量分析 + IR 信号的特色评分体系
3. **定量分析** - 财务指标、资金流向、估值分析
4. **智能问答** - 自然语言查询股票/板块信息
